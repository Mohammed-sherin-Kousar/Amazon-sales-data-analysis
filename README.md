# Amazon Sales Data Analysis

##  Project Overview

Developed an end-to-end **Amazon Orders Data Analysis project** to clean, analyze, and visualize e-commerce order data. The project uses Python for data cleaning and EDA, SQL for business analysis, and Power BI for interactive dashboard reporting.

##  Objective

* Analyze Amazon order and sales data.
* Clean and transform raw transactional data.
* Identify sales, order, revenue, product, and geographical patterns.
* Perform business analysis using SQL.
* Build an interactive Power BI dashboard for reporting and insights.

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* SQL / MySQL
* Power BI
* DAX
* Power Query
* Excel / CSV
* Google Colab

##  Key Steps

* Loaded and explored the Amazon orders dataset.
* Handled missing values and duplicate records.
* Standardized categorical fields such as status, category, city, and state.
* Converted date, quantity, and amount fields into appropriate formats.
* Identified potential outliers using the IQR method.
* Created derived fields including Month, Year, Day, Weekday, and Revenue.
* Performed EDA to analyze product categories, sizes, order status, cities, and states.
* Loaded the cleaned data into MySQL for SQL-based analysis.
* Created SQL queries for sales, orders, revenue, fulfilment, cancellation, promotion, and product analysis.
* Built an interactive Power BI dashboard with KPIs, charts, filters, and business insights.

##  Analysis Performed

* Sales by SKU, Category, and Size
* Top States and Cities by Order Amount
* Orders by Product Category
* Orders by City and State
* Daily, Weekly, and Monthly Revenue Trends
* Fulfilment Channel Analysis
* Ship-Service Level vs Order Amount
* Quantity vs Sales by Category
* Cancellation Analysis by Category and Size
* Promotion vs Average Order Amount
* Product Category, Size, and Style Distribution
* Revenue Contribution by Category

##  Result

* Successfully transformed raw Amazon order data into a cleaned analytical dataset.
* Created derived business metrics such as Revenue, Month, Year, and Weekday.
* Performed SQL-based analysis to identify sales, order, fulfilment, product, and geographical patterns.
* Developed an interactive Power BI dashboard for KPI monitoring and business analysis.
* Generated visual reports and insights from the cleaned data.
